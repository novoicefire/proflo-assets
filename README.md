# proflo-assets

Public image hosting for ProfLo-Course-Tools email announcements.

Gmail and Outlook do not show `data:` images, so the attendance banners are served from here:

- `banners/ncnu-banner-regular.png`
- `banners/ncnu-banner-celebrate.png`

The source PNGs and the generator live in ProfLo-Course-Tools (`references/assets/`).
Only put public, non-personal images in this repository.
